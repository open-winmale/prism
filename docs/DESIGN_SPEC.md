# UI/UX 设计规格 · 报告化工作台（v1.0）

> 版本 v2.0 ｜ 2026-10-21 ｜ 适用：工作台（`/company/:symbol/:workspace`）及后续所有 UI 改动
> 本文件是**还原度的标尺**：任何 UI 改动先对照本规格。与旧版（v0.x Hero 报告）冲突处，以本文件为准。

---

## 1. 设计原则

1. **结论优先**：首屏 5 秒内给出「稳健 / 需关注 / 高风险 / 数据不足」+ 一句话 thesis + 证据 chips。
2. **证据随行**：每个结论可展开到证据；每个证据可回到报告期 / 科目 / 公式 / 来源。
3. **口径诚实**：缺失显示 `—` 不显示 0；季度口径明示单季推导与同季同比；审计意见、数据截至常驻。
4. **一屏一问**：七个工作区各回答一个问题；区块标题即问题。
5. **克制（反 demo）**：无 emoji、无卡片墙、无营销 hero、无大留白；细线分隔 + 信息密度优先。

## 3. 布局

### 3.1 桌面（≥1024px）

```
┌ Topbar 56px：品牌 · 搜索 · 数据源 · 专业版 ↗ ┐
├ Sidebar 216px：工作区 01–07 · 来源/方法论 ┤
├ Main：CompanyHeader →（阅读提示）→ 工作区内容 → 页脚 ┤
```

### 3.2 移动（<768px）

- Topbar 换行（搜索整行）；Sidebar 隐藏；底部导航 5 项（概览/财报/同业/风险/更多）。
- 结论条置顶（首屏内可见，E2E 断言）；KPI 两列；表格容器横向滚动；点击目标 ≥32px。

### 3.3 路由

`/company/:symbol/:workspace?`，workspace ∈ overview|financials|quality|peers|valuation|risk|tracking；`/analyze?symbol=` 重定向到 `/company/:symbol/overview`。

## 4. 组件规格（`src/components/ui/`）

### 4.1 CompanyHeader
公司名+代码 / 行业·期间·审计·SourceBadge / 右侧行情（价格、涨跌红绿、PE/PB/ROE/PE 3Y/股息/截至）。快照模式右侧显示「示例快照 · 无实时行情」。

### 4.2 VerdictStrip
左边框 3px 语义色；状态徽章（稳健/需关注/高风险/数据不足）+ 完整度（N/M 项已核查）+ 审计 + as-of；thesis 一句话；证据 chips + 风险 chips（琥珀底）。

### 4.3 KpiTile
标签（10px 大写）/ 数值（tabular）/ meta / 可选 sparkline（22px SVG 折线）。五格一行，≤1100px 三列，≤767px 两列。

### 4.4 DataTable
`.wb-table`：sticky 表头（11px 大写灰）、可选 sticky 首列、数字右对齐、行 hover、缺失 `—` 灰色、section 行加粗浅底。

### 4.5 StatementTable（三表列组）
- 每期一个列组：`原值` + 子列（`同比` | `占比`，工具行切换）；双行表头（组头 colspan=2 + 子头），子头 sticky top:30px。
- 期间标签：年度 `2025`；季度 `2025Q3`。
- 金额折亿元（千分位 1 位小数）；pct 行（毛利率等）显示 `%`，占比子列显示 `—`。
- 科目行可点（`is-clickable`，hover 品牌色下划线）→ `LineItemDialog`；section 行不可点。
- 季度口径：流量为单季视图（`singleQuarterView`），子列同比 = **同季对比**（`sameQuarterYoyOf`），子列头显示「同比(同季)」。
- 脚注：单位 / 子列口径 / 占比分母 / 缺失规则。

### 4.6 LineItemDialog
`role=dialog aria-modal`；头部（科目名 / 区间 / 来源（三表科目|派生口径）/ 单位）+ 关闭（ESC / 遮罩 / 按钮）；三视图（趋势折线 / 同比柱 / 数据表：原值+同比+占比）；高 260px。

### 4.7 ChartFrame
标题 + 单位 → EChart → 脚注（参考线说明 / 来源 / 数据截至）。`height` 可覆盖（小倍数 150、下钻 260）。空数据由 EChart 占位（「该指标无数据 · 标题」），禁止空白画布。

### 4.8 RiskRow
四态（✓ 安全 / ✗ 高危 / ！ 中度 / — 数据不足）+ 名称 + 佐证 + 标签；展开：为什么（触发/安全/缺口）→ 下一步（品牌左边框）→ 老唐视角（琥珀左边框）→ 「在财报中查看科目 →」回链（有 `field` 时）。

### 4.9 SourceBadge
`内置快照 · 0 EC`（琥珀）/ `接口取数 · N EC | 本地缓存 · 0 EC`（绿）/ 未取数（灰）。来源按 dataset 实际 `kind` 判断，禁止按 provider 判断。

## 5. 图表规格

| 项 | 规格 |
| --- | --- |
| 默认高度 | 240（`h-60 lg:h-72`）；ChartFrame 可传 `height`（小倍数 150、下钻 260） |
| 参考线 | 琥珀虚线 1px + 端点标签；例：收现比 100%、CFO 警戒线、行业中位数（x/y 轴） |
| 散点 | 同业灰点 8px、当前公司红点 12px + 名称标签；tooltip「PE x / ROE y%」 |
| 序列色 | §2.1 图表色板；空数据文字占位 |
| 坐标轴 | 10px；y 轴名 = 单位 |

小倍数：概览「核心趋势」2×2（营收 / 归母净利 / 毛利率+自身均值线 / CFO/净利+100% 线），≤767px 单列。

## 6. 状态规格

| 状态 | 表现 |
| --- | --- |
| 加载 | 保留壳 + 骨架块 + 进度（`done/total 张报表`）；禁止整页替换 |
| 空 / 缺失 | `—` + 说明缺什么 + 替代路径（看示例 / 连接开放平台 / 去专业版）；禁止显示 0 或「安全」 |
| 数据不足（检查项） | 四态之一「数据不足」，计入 verdict（na≥3 → 数据不足，不判安全） |
| 错误 | `role=alert` 红底 + 重试按钮；原文只进控制台 |
| 快照模式 | 同业/估值/PE 分位显式降级提示，不伪装数据 |

## 8. 文案与语气

- 完整句子；数字与单位间不留空格（`240 亿`）；亿元 / % 统一。
- 判断必须带限定（「需核查」「可能」）；禁止「造假 / 暴雷」定罪式措辞。
- 估值只回答「贵不贵」，不回答「值不值得买」；不给目标价。
- 数据展示处保留「仅供学习，不构成投资建议」。

## 9. 可访问性基线

- 对比度 ≥4.5:1；辅助文字 ≥11px 且用 `--wb-slate`（不用更浅）。
- dialog：`role=dialog` + `aria-modal` + ESC + 焦点移入关闭钮。
- 状态不仅靠颜色（✓ ✗ ！ — 符号 + 文字标签）。
- 图表 `role=img` + aria-label；展开行 `aria-expanded`。
