## 0. TL;DR

**综合评分：5.2 / 10。工程质量过关，产品定位与信任机制不合格。**

三个核心判断：

1. **现状不是「专业版精简版」，而是「白酒排雷清单 + 12 个孤立模块」。** 它复制了专业版的菜单形状，却没有复制专业版真正的资产——**证据链、跨期对比、口径说明、数据严谨性**。
2. **三个场景 Tab（防踩雷/看质地/验真伪）是伪需求。** 用户不是先选场景再看证据，而是先看结论，再沿着一条连续叙事往下查。场景 Tab 把同一份数据切成三份，进入「更多维度」后还会丢失场景上下文。
3. **开放平台的能力被低估了。** 当前只用了 `finance view=raw`；`card`（行情/估值/3 年分位/股息/成长/行业层级）和 `members`（行业成分与估值中枢）基本没用。补上这两类数据，才能做出「结论卡 + 同业坐标 + 估值」这些业界产品都有的首屏。

**最新版专业版的变化进一步印证了边界：** winmale-v2 新增了「盈利预测」「投资收益率」「一致行动人」「并购重组」「个股提醒」，专业版正在向**预期、回报、筹码、事件、提醒**扩张。开源版不应该追这些数据域，而应该把「三表诊断」做透，并在每个断点把用户交回专业版。**免费给完整结论，付费卖深度与数据域**，这是最清晰的分工。

**定位（已确认）：个人投资者的专业版简化版，核心是快速上手。** 保留专业版的分析框架与证据链，去掉机构级复杂度；零登录、零配置先看到完整示例，3 分钟完成一次自己的公司分析。

**建议：** 重做为「一份可核查的财务诊断备忘录」——首页搜索 → 报告（结论 + 五维 + 五章 + 跟踪）→ 数据实验室 → 同业对比；白酒作为第一个行业镜头，引擎按通用 A 股设计。先修 9 个 P0 信任问题，再动 UI。

## 2. 专业版盘点（对齐最新版）

### 2.1 专业版到底有什么

专业版是 `AnalysisPage` 上的全屏覆盖层，不改路由。导航由一个注册表驱动（`src/features/analysis/proNav.tsx:61-130`），当前 **8 个一级组**：

| 一级组 | 条目 | 状态 | 对开源版的价值 |
| --- | --- | --- | --- |
| 基本面 | 投资收益率、盈利能力、扣非 PEG、DCF 估值、债务安全、现金流量 | 6 个可见；其余 9 个是 `return null` 占位 | **盈利能力/债务/现金流三页的判据可移植**；ROI/PEG/DCF 属专业版 |
| 盈利预测 | 机构预测 | 新增，A 股 | 一致预期/EPS/评级/分歧度，需东财 F10，开源版拿不到 |
| 经营分析 | 主营构成、重大合同、经营评述 | 已上线，A 股为主 | 依赖分部/公告，开源版不做 |
| 股东股权 | 十大股东、一致行动人、持股人数、质押、解禁、回购、并购重组 | 7 条，新增一致行动人与并购重组 | 依赖 F10，开源版不做 |
| 机构持仓 | 机构占比、沪股通、国家队 | 已上线 | 依赖 F10，开源版不做 |
| 公司投资 | 募集资金、长期股权、理财、证券 | 已上线 | 依赖 F10，开源版不做 |
| 舆情公告 | 重要公告、担保、处罚诉讼 | 已上线 | 依赖公告库，开源版不做 |
| 高管员工 | 高管、员工 | 已上线，A/H | 依赖 F10，开源版不做 |

**关键事实：专业版的菜单比实现宽。** 15 个基本面页里只有 6 个可见，9 个仍是 `return null` 占位（`pages/fundamentals/index.tsx:44-51`）。这提醒我们：**不要照着专业版菜单做开源版**，否则会把「占位页」也复制成「功能清单」。

### 2.2 最新版新增了什么（本轮重新调研的重点）

| 新增 | 页面 | 回答的问题 | 数据源 | 可移植性 |
| --- | --- | --- | --- | --- |
| 盈利预测 | `pages/forecast/Page.tsx`（697 行） | 券商怎么看未来 3 年？预期在变好还是变差？分歧多大？ | 东财 F10 盈利预测（A 股） | **低**：开源平台无一致预期 |
| 投资收益率 | `pages/fundamentals/roi/Page.tsx` | 持有 1/3/5/10 年到底赚多少？相对指数超额多少？ | 复权行情 + 指数序列 | **低**：开源平台无长历史复权行情 |
| 一致行动人 | `pages/shareholder/concert/Page.tsx` | 同一批筹码背后的组合控制了多少？成员有没有变？ | `cn.yzxdrindex.LIST` | **低**：F10 数据 |

| 个股提醒 | `stockAlert/StockAlertHub.tsx` | 指标/公告/买卖点提醒 | 订阅后端 | **低**：需要账户与推送基础设施 |

这些新增页面的价值不在「开源版也要有」，而在于它们展示了专业版的三条产品原则，值得开源版学习：

1. **口径写进界面**：盈利预测页把「A=已实现 / E=预测」「一致预期=近六月平均」「分歧度=(乐观−悲观)/中位数」直接挂在问号里（`pages/forecast/Page.tsx:216-231`）。
2. **数据坑显式标注**：一致行动人页标注「沿用期」（源端 `_forward_filled`），最新读数跳过沿用行（`concert/Page.tsx:28-36`、`concert/model.ts:139-150`）。
3. **未披露 ≠ 0**：并购重组页对 1 元/0 元的占位金额、非人民币金额分别处理，汇总只算人民币（`ma/api.ts:22-38`、`ma/Page.tsx:20-30`）。

### 2.3 专业版真正的护城河

不是 15 个菜单，而是四件事：

1. **证据工作流**：报表页的每个格子可挂同比/占比/周转、异常三角、检测三角、附注「注」、图表按钮；结论永远能回到科目和年份（`components/AnalysisProSheet.tsx`，约 2,640 行）。
2. **对比能力**：最多 3 家对比公司，按财年标签对齐，逐行显示差异；异常检测支持「波动/差异/趋同」三类（`components/AnalysisProCompare.tsx`、`pages/balance-sheet/detect.ts`）。
3. **判据而非打分**：盈利能力 16 条、债务 10 条、现金流 9 条、资产负债 10 条，命中只给证据与「为什么」，页面明确「不下结论、不打分」（`pages/fundamentals/profitability/anomaly.ts`、`pages/fundamentals/debt/anomaly.ts`、`pages/fundamentals/cash-flow/anomaly.ts`、`pages/balance-sheet/assetAnomaly.ts`）。
4. **口径与数据严谨性**：财务公司现金口径、沿用值、A/E 标记、未披露≠0、不同币种不相加、报告期/公告日分离。

**开源版最该复制的是第 1、3、4 条；第 2 条可以简化为「行业估值分位 + 最多 3 家深对比」。**

### 3.3 十个可借鉴模式

1. **首屏结论卡**：一句话判断 + 3–5 个证据数字 + 数据截止 + 置信度/完整度。
2. **指标带**：数值 + 5 年 sparkline + 行业中位数 + 分位/排名；不是大柱状图。
3. **结论—假设—证据—风险**四段式：每个结论都能展开到证据，再给出「什么会推翻它」。
4. **风险清单四层**：公司级结论 → 维度分 → 规则信号 → 科目/年份证据；每层可下钻。
5. **同业基准线**：默认同业组 + 可编辑 + 中位数/20/50/80 分位 + 样本数 n。
6. **口径透明**：公式、分子分母出处、报告期、数据来源、缺失状态常驻或一键展开。
7. **可追溯**：每个数字能点回报表行/公告/附注；免费版至少能点回三表。
8. **免费给完整结论，付费卖深度**：免费给判断与核心证据；付费卖更长历史、附注、预测、提醒、导出、API。
9. **移动端渐进披露**：首屏结论 + 3 个指标卡，证据折叠；不隐藏证据。
10. **状态而非定罪**：用「需核查/异常/数据不足」，不用「造假/暴雷」；单指标不下结论。

### 3.4 三个反模式

1. **单一总分/评级无拆解**：94 分/雷达图很好看，但不知道 why；跨行业失真。
2. **恐吓式排雷**：单一 Beneish/红灯=造假，忽略行业豁免与误报。
3. **数据堆砌**：首屏全是表格/指标，没有「so what」。

### 3.5 三个参考页面结构

**A. 个股结论页（Morningstar + Simply Wall St）**

```
[标题条] 名称/代码/价格/日期/数据源
[结论卡] 稳健/关注/高风险 | 一句 thesis | 数据完整度 | 审计意见
[五维条] 盈利 / 成长 / 现金 / 安全 / 估值：状态 + 主指标 + 趋势
[三条证据] 营收利润 | ROE/ROIC | OCF/净利润
[风险条] Top 3 风险 + 什么会推翻结论
[Tabs] 财报 | 质量 | 同业 | 分红 | 叙事
```

**B. 财报透视/排雷页（GuruFocus + 读值）**

```
[质量总览] 盈利质量/现金流/资产负债表/会计异常 4 个子状态 + 数据完整度
[结论—证据—反证] 三栏或手风琴
[趋势图] 收入/利润/OCF/FCF/应计
[排雷清单] 检查项 | 结果 | 严重度 | 解释 | 来源 | 解除条件
[模型卡] Piotroski / Altman / Beneish + 适用性与局限
[脚注] 公式/口径/来源
```

**C. 同业比较/估值页（TIKR + Finbox + Koyfin）**

```
[Peer 头] 自动同业组 + 可编辑 chips + “为什么是这些”
[Comps 表] 估值/成长/利润率/ROE/杠杆/分红 + 中位数/分位
[象限图] ROIC vs EV/EBIT；增长 vs PE
[估值桥] 相对估值/历史分位/PR + 关键假设
[CTA] 导出/加自选/分享
```

### 4.2 做对了什么

- 纯 TS 引擎与 UI 解耦，`engine/` 可复用到任意前端。
- 三场景共用一次取数，切场景零 EC；24h 缓存与内置快照降级。

**P0-1 数据来源标签错误：内置快照被标成「实时接口」**

**P0-2 缺数据被当成「安全」**

- 修法：`LiveProvider.getDataset` 和 `SnapshotProvider.getDataset` 返回前统一跑 `verifyDataset`；`error` 阻断渲染，`warn` 在报告头显示；补 provider 单测。

**P0-4 五粮液 2025 快照严重不勾稽**

**P0-5 自由现金流单位错误**

**P0-6 ROE 主导驱动量纲不可比**
- 位置：`src/engine/analysis/profitDrivers.ts:63-66`
- 证据：直接比较净利率（~0.5）、资产周转（~0.5）、权益乘数（~1.3）的原值，杠杆永远最大；茅台会被判「杠杆驱动」。

**P0-7 季度口径声明与实现不符**

### 4.4 根因

1. **功能清单思维**：照着专业版菜单做模块，而不是照着专业版的证据工作流做报告。
2. **数据层只用了一半**：只用 `raw`，没用 `card`/`members`，所以没有估值、股息、行业分位、首屏结论。
3. **用分数替代判断**：0–100 总分是伪精确；专业版自己都明确「不下结论、不打分」。
4. **用场景 Tab 替代叙事**：三个场景把一份报告切成三份，用户失去上下文。
5. **缺数据→安全**：这是财报产品最不可接受的信任问题。
6. **成本/来源不透明**：用户不知道数据从哪来、花了多少、是否最新。
7. **设计规格未落地**：`DESIGN_SPEC` 写得不错，但实现是通用卡片堆叠 + emoji + 大留白，没有形成「研究备忘录」的质感。

## 5. 重设计

### 5.1 定位与边界

**一句话：个人投资者的专业版简化版——保留专业版的分析框架和证据链，去掉机构级复杂度，3 分钟上手，5 分钟读懂一家公司。**

不是「白酒排雷工具」，也不是「财报数据浏览器」，而是**专业版能力地图的精选版**：把专业版里个人投资者最常用、最看得懂、最能形成判断的部分抽出来，做成一份可核查的财务诊断备忘录。

四条产品原则：

- **快速上手**：零登录、零配置先看到完整示例；一个搜索框进入报告；默认 5 年/3 年、默认行业组、默认阈值，不要求用户先学口径。
- **结论先行**：首屏给出「稳健 / 关注 / 高风险 / 数据不足」+ 一句话 thesis + 3 条证据 + 2 条风险。
- **证据可查**：每个结论都能回到报告期、科目、公式、数据来源；每个缺失都明示。
- **口径诚实**：累计/单季、年度/季度、合并/母公司、报告期/公告日、行业分类全部写清。

**专业版 vs 简化版的分工：**

| 能力 | 简化版（本产品） | 专业版 |
| --- | --- | --- |
| 三表、比率、共同比、同比/占比/周转 | 完整可查 | 完整 |
| 盈利 / 现金 / 债务 / 估值诊断 | 五维 + 五章 | 15 个专题页 + 45 条判据 + 附注穿透 |
| 同业估值分位 | 默认行业组 + 最多 3 家深对比 | 任意对比 + 更长历史 + 更多指标 |
| 附注 / 分部 / 量价 | 不做，报告内入口引导 | 完整 |
| 盈利预测 / 投资收益率 | 不做，报告内入口引导 | 完整 |
| 股东 / 机构 / 公告 / 提醒 | 不做，报告内入口引导 | 完整 |
| 使用门槛 | 零登录；示例 0 EC；AppId 可选 | 登录 / 会员 / 更完整数据 |

**范围：**

- **支持**：A 股非金融企业（制造业、消费、科技、周期等）。
- **首发样例**：3 家白酒真实快照 + 1 家制造业对照样例；后续补 2–3 家真实非白酒样例，证明「不是白酒专用工具」。
- **行业镜头**：白酒作为第一个深镜头（合同负债/营收、销售费用率、毛利率对自身均值；不做量价/产品结构，因为开放平台三表拿不到）。
- **不做**：银行/保险/证券/REITs；港股/美股；附注/分部/量价；股东/机构/公告；盈利预测；投资收益率；提醒；选股/回测。
- **交回专业版**：每个不做的数据域，在报告对应位置给情境化 CTA，而不是顶部一条通栏广告。

**定位落地：通用引擎 + 行业镜头，而不是白酒-only。**

- 专业版本身就是「通用财务框架 + 行业化阈值」；简化版如果只做白酒，会退化成行业小工具，与「专业版简化版」的定位冲突。
- 开放平台 `card` 已返回 `industry_l1/l2/l3`，`members` 可按申万行业名取成分——通用行业的同业组是可行的。
- 通用引擎 + 白酒专属规则可以共存：默认 `GENERAL_T`，`industry === 'liquor'` 时切 `LIQUOR_T`。
- 首发只开白酒样例是「内容节奏」，不是「架构边界」；IA 与引擎必须按通用设计，避免以后重写。

### 5.2 快速上手（Onboarding）

**目标：首次访问 60 秒内看到一份完整示例报告；3 分钟内完成一次自己的公司分析；全程不需要读说明书。**

#### 首访路径

1. 打开首页：一句定位 + 搜索框 + 「先看一份示例报告」按钮（0 EC，内置快照）。
2. 点示例：直接进入完整报告；首屏有一行「这份报告怎么看」的可关闭提示：**先看结论 → 再看五维 → 最后看跟踪清单**。
3. 搜索自己的公司：有 AppId 直接取数；没有 AppId 时，搜索框下方出现内联引导卡（申请只需 1 分钟），不阻断示例阅读。
4. 报告内：术语首次出现带一句人话解释；「为什么重要 / 下一步查什么」内联展开；不跳转到帮助页。
5. 想更深：在对应章节出现专业版 CTA（附注/预测/股东/提醒），不是首屏弹窗。

#### 七条规则

1. **零登录、零配置先看到完整价值。** 示例报告必须是一份完整报告，不是截图或缩水版。
2. **一屏一个主行动。** 首页只有「搜索 / 看示例」；报告首屏只有「看结论 / 查证据」。
3. **默认值优先。** 5 年、3 年分位、默认行业组、默认阈值；高级参数收进「口径」抽屉。
4. **术语首次出现给一句解释。** 第二次不再打扰；解释里带一个数字例子。
5. **每个结论配「为什么」和「下一步」。** 用户不仅知道结论，还知道该核查什么。
6. **空态/错误态给替代路径。** 没 AppId → 看示例；取数失败 → 重试/换示例；数据缺失 → 去专业版补。
7. **专业版 CTA 只在用户产生「想看更深」的意图时出现**，不在首屏拦路，不做通栏广告。

#### 首访验收

- 不填 AppId，从首页到完整报告 ≤ 2 次点击。
- 首屏 5 秒内能说出「这家公司财务上怎么样」。
- 30 秒内能找到至少 1 条支撑数字。
- 3 分钟内能完成一次「搜索 → 报告 → 切换章节」。
- 移动端单手可完成上述路径。

### 5.6 五章内容规格

#### 01 生意质量（这门生意好不好？）

| 指标 | 公式/口径 | 数据来源 | 呈现 |
| --- | --- | --- | --- |
| ROE（归母） | 净利率 × 总资产周转 × 权益乘数（相邻期均值） | raw | 当前值 + 5y 趋势 + 行业分位 |
| ROIC | EBIT × (1 − 有效税率) / (有息负债 + 归母权益 − 货币资金) | raw | 当前值 + 5y；WACC 固定 5% 基准另标 |
| 毛利率 | (营收 − 营业成本) / 营收 | raw | 当前值 + 5y + 自身 5 年均值 |
| 净利率 | 归母净利 / 营收 | raw | 当前值 + 5y |
| 费用率 | 销售/管理/研发/财务费用 / 营收 | raw | 四行小倍数图 |
| 营收/归母净利增速 | YoY；季度用单季 | raw | 当前值 + 5y |
| SGR | ROE × (1 − 分红/净利) | raw + card 股息率×市值 | 与 actual growth 对照 |
| 白酒镜头 | 合同负债/营收、销售费用率、毛利率 vs 自身 5 年均值 | raw | 3 行指标 + 趋势 |

**状态判定（透明规则，不打分）：**

- 强：ROE ≥ 15% 且 ROIC ≥ 10%，毛利率/净利率 3 年趋势不下行。
- 中：ROE 8–15%，或一项核心指标连续 2 年下行。
- 弱：ROE < 8%，或毛利率/净利率连续 3 年下行。
- 数据不足：ROE/ROIC/毛利率任一缺失。
- 有行业分位时，优先用「≥ 行业中位数 + 趋势」判定，绝对值仅作兜底。

#### 02 利润含金量（利润是真的吗？）

| 指标 | 公式/口径 | 数据来源 | 呈现 |
| --- | --- | --- | --- |
| CFO/归母净利 | 经营现金流 / 归母净利 | raw | 5y 柱线 + 1.0 参考线 |
| FCF/归母净利 | (CFO − Capex) / 归母净利 | raw | 5y |
| 应计利润/总资产 | (归母净利 − CFO) / 平均总资产 | raw | 5y；负值更好 |
| CCC | DSO + DIO − DPO | raw | 5y；缺失→null |
| 应收 vs 营收 | 应收增速 − 营收增速 | raw | 5y 双线 |
| 存货 vs 营收 | 存货增速 − 营收增速 | raw | 5y 双线 |
| 单季异常 | 单季营收/净利/CFO 的同比与季节分布 | raw（季度） | 仅季度模式；缺期→关闭卡片 |
| Piotroski F9 | 9 项打分 | raw（两年） | 7/9 + 组件表 |
| Altman Z | 5 因子 | raw + card 市值 | 分区 + 局限说明 |
| Beneish M | 8 因子 | raw（需折旧字段） | 数据不足则置灰，不硬算 |

**状态判定：**

- 高：CFO/NP ≥ 1 连续 3 年，应计 < 0，CCC 稳定。
- 中：CFO/NP 0.8–1，或一项异常。
- 低：CFO/NP < 0.8 连续 2 年，或应计 > 5% 总资产。
- 数据不足：CFO/NP 或应计缺失。

#### 03 财务安全（有没有雷？）

风险清单按四组组织，每组 2–3 项，合计 8–10 项：

| 组 | 检查项 | 阈值/规则 | 数据来源 |
| --- | --- | --- | --- |
| 利润质量 | 应收增速 > 营收增速（连续 2 年且应收/营收 > 行业门槛） | 行业化 | raw |
| 利润质量 | 存货增速 > 营收增速（白酒用成品口径；无成品明细则用总额+说明） | 行业化 | raw |
| 利润质量 | 非经常性损益/净利 > 30% | 30% | raw（需补字段） |
| 资产质量 | 商誉/归母权益 > 30% | 30% | raw（需补字段） |
| 资产质量 | 其他应收/总资产 > 5% | 5% | raw |
| 资产质量 | 在建工程/固定资产 > 30% 且连续 2 年上升 | 30% | raw |
| 负债安全 | 有息负债/总资产 > 30% 且现金/短债 < 1 | 30%/1 | raw |
| 负债安全 | 大存大贷：货币资金 > 有息负债 且 有息负债/总资产 > 30% | — | raw |
| 负债安全 | 利息保障倍数 < 3 | 3 | raw（需补利息费用） |
| 治理/审计 | 审计意见非标准无保留 | — | raw `opinionType` |

每项统一四态：`触发 / 关注 / 安全 / 数据不足`；每项必须有 evidence、why、next、source。**不再出现「全部通过」但当 N 项无数据的情况；顶部直接写「7 项已核查，3 项数据不足」。**

#### 04 估值与同业（贵不贵？）

| 指标 | 公式/口径 | 数据来源 | 呈现 |
| --- | --- | --- | --- |
| PE-TTM / PB / PS-TTM | 行情 | card | 当前值 + 行业分位 |
| PE/PB 3 年分位 | `pct_pe_3y` / `pct_pb_3y` | card | 分位条；标注「自身 3 年」 |
| PR（市赚率） | PE / (ROE × 100) | card | 当前值 + 解释；不给买卖信号 |
| 股息率 | `bonus_rate_ttm` | card | 当前值 + 上年 |
| 行业分位 | 同业组内排名 [0,1] | members | 分位条 + n |
| 同业表 | 市值/PE/PB/PS/ROE | members | 21 家（白酒）或行业组；当前公司高亮 |
| 散点 | ROE vs PE | members | 中位数十字线 |

**状态判定：**

- 偏便宜：PE/PB 3 年分位 < 30% 且行业分位 < 30%。
- 中性：30%–70%。
- 偏贵：> 70%。
- 亏损/负 PE：PE 置 null，只用 PB/PS，并明确「亏损公司 PE 不适用」。
- 永远附一句：「估值只回答贵不贵，不回答值不值得买。」

#### 05 跟踪清单（接下来看什么？）

3–5 个指标，每个包含：当前值、阈值、方向、数据来源、下次披露时间（若能拿到）。

示例（白酒）：

- 合同负债/营收：当前 9.2%，阈值 < 5% 或连续 2 季下降 → 渠道信心转弱。
- CFO/归母净利：当前 1.18，阈值 < 0.8 连续 2 年 → 利润含金量恶化。
- 毛利率：当前 91.2%，阈值 < 自身 5 年均值 − 2pt → 提价能力见顶。
- PE 3 年分位：当前 35%，阈值 > 70% → 估值偏贵。
- 有息负债率：当前 0%，阈值 > 30% → 杠杆风险。

最后一行永远是「什么会推翻本报告的结论？」——把 thesis 变成可证伪的清单。

### 5.7 数据实验室

`/report/:symbol/data`

- 三表切换：利润表 / 资产负债表 / 现金流量表。
- 口径：年度 5 年 / 季度 8 期；原值 / 同比 / 占比 / 周转。
- 表格：sticky 首列 + sticky 表头；数字右对齐；单位在表头；缺失显示 `—`，不显示 0。
- 共同比：BS ÷ 总资产；PL ÷ 营收；CF ÷ 经营现金流。
- 指标字典：每个指标可点开公式、数据来源、缺失状态。
- 导出 CSV；报告结论导出 PNG。
- 不做附注/PDF；在表格底部放「看附注明细 → 专业版」。

### 5.8 同业对比

`/compare?symbols=600519,000858,000568`

- 默认同业组：`card.industry_l3` → `members(key=行业名, kind=industry)`；白酒默认 21 家。
- 表：市值 / PE / PB / PS / ROE / 股息率 / 营收增速 / 净利增速 / 有息负债率；数据来自 `members`（估值/ROE）+ 可选 `card`（成长/股息/负债）。
- 散点：ROE vs PE；当前公司高亮；中位数十字线。
- 差异解释：只描述「高 ROE 低 PE」等相对位置，不给买卖建议。
- 深对比：最多 3 家，拉取三表（每家约 3 万 EC），必须二次确认并显示预估；结果缓存 24h。
- 说明：行业分位是横截面，不是历史分位；样本数 n 常驻。

### 5.12 验收标准

1. **快速上手**：不填 AppId，从首页到完整报告 ≤ 2 次点击；60 秒内看到第一份完整示例；3 分钟内完成一次「搜索 → 报告 → 切换章节」；移动端单手可完成。

8. 375px 下：结论、五维、证据、表格都可读；没有隐藏佐证；图表不溢出。
9. 术语首次出现有解释；空态/错误态都有替代路径，不出现死胡同。
10. 121 个既有测试 + 新增测试全绿；`typecheck`/`lint`/`test`/`build` 全绿；E2E 覆盖搜索→报告→对比。

## 6. 需要确认的落地决策

1. **产品范围：定位已明确为「专业版简化版」；范围建议通用 A 股 + 白酒镜头。**
   - 推荐：IA 与引擎按通用 A 股设计，首发内容先开白酒样例（3 家）+ 1 家制造业对照；后续补真实非白酒样例。
   - 需要确认的是「首发是否只开白酒样例」，不是「是否只做白酒」；架构不要退回白酒-only。
   - 理由：开放平台 `card.industry_l3` + `members` 已支持通用行业组；专业版本身就是通用 + 行业化阈值；只做白酒会与「专业版简化版」的定位冲突。

2. **是否取消 0–100 质量总分？**
   - 推荐取消，改为五维三态 + 趋势 + 同业分位；分数只作为附录参考。
   - 理由：专业版自己明确「不下结论、不打分」；总分与「合同负债 0 分」的短板会互相矛盾。

3. **官方站的数据架构：纯前端 + 用户 AppId，还是 BFF 共享缓存？**
   - 推荐本期保持纯前端 + 用户 AppId（与现有开源定位一致）；官方站用示例快照。
   - 若要做「打开即用」的官方站，再上 BFF（Cloudflare Workers/Vercel），共享缓存 + 限速 + secret 不下浏览器。

4. **是否继续 Vue3？**
   - 推荐继续 Vue3，不迁 React。引擎是纯 TS，可复用；迁移只会增加成本，不解决产品问题。

5. **Altman/Piotroski/Sloan 是否进 v1？**
   - 推荐进 v1（数据可得、规则透明、对「排雷」价值高）。
   - Beneish 先验证折旧摊销字段；字段不足就置灰「数据不足」，不要硬算。

6. **是否保留三个场景作为「保存视图」？**
   - 推荐不保留为主 IA；如果用户需要，可做成「结论/现金/风险」三个分享锚点，而不是三个 Tab。
