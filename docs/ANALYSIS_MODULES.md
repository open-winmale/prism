# 分析模块与老唐方法论

`财报透视` 的每一个分析模块都围绕「**解决一个投资问题**」展开，并遵循老唐《手把手教你读财报》的方法论。所有图表来自四类分析方法：趋势 / 结构 / 横向 / 纵向。

## 1. 四类分析方法

| 方法 | 回答的问题 | 典型图表 | 工厂函数 |
| --- | --- | --- | --- |
| **趋势** | 这个指标随时间怎么变？（同比/环比） | 折线、同比柱状、多指标同图 | `trendLine` / `yoyBars` / `metricComparisonSpec` |
| **结构** | 内部构成占比如何？ | 饼图、堆叠占比 | `pieShare` / `stackedShares` / `percentBars` |
| **横向** | 与同业/对手比如何？ | 可换轴散点、横截面分位、关键指标小倍数、分组柱 | `compareBars` / `peersScatter` / `peerPercentileSpec` / `peerKeyMetrics` |
| **纵向**（共同比） | 利润/资产里每一项的相对分量？ | 共同比堆叠/表 | `commonSizeStacked` / `commonSizeTable` |

> 模块只产出框架中立的 `ChartSpec`（`type: line|bar|horizontalBar|pie|scatter|stackedBar|groupedBar|waterfall|heatmap|table`），由 UI 翻译成 ECharts。
>
> 对比优先：同一张图优先放 2–3 个同单位序列，或统一「基期=100」；量纲不同禁止共用一根轴。门线/中位数/零线用 `refLines.kind` 区分配色，缺失保持 null。详见 [`CHART_DESIGN.md`](./CHART_DESIGN.md)。

## 3. 老唐排雷九条（mineDetect 模块）

排雷是「先看防假，再看质」的第一步。以下九条对应 `src/engine/laotang/rules.ts`，每条带红绿灯等级：

| # | 规则 id | 检查内容 | 等级 | 老唐原话要点 |
| --- | --- | --- | --- | --- |
| 1 | `ar_growth` | 应收增速持续高于营收增速 | 高危 | 应收猛增、营收没动 = 虚假繁荣第一信号，货可能没真卖出去 |
| 2 | `inventory_growth` | 存货增速持续高于营收增速（且存货/营收较高） | 高危 | 存货积压 = 滞销或虚增库存，结合跌价准备看 |
| 3 | `cfo_vs_profit` | 经营现金流长期低于净利润 | 高危 | 利润是算出来的，现金是赚到的，含金量存疑 |
| 4 | `other_receivables` | 其他应收款占资产异常庞大 | 高危 | 「装不下只好藏这里」的科目，常是大股东占用资金 |
| 5 | `big_deposit_big_loan` | 大存大贷（货币资金 > 有息负债且负债/资产高） | 中度 | 账上躺着钱却巨额付息，钱的真实性与受限情况存疑 |
| 6 | `goodwill` | 商誉占净资产过高 | 中度 | 商誉是并购溢价不是资产，减值会吞噬利润 |
| 7 | `nonrecurring` | 净利润主要靠非经常性损益 | 中度 | 卖资产/补贴/投资收益撑的盈利不可持续 |
| 8 | `gross_margin_anomaly` | 毛利率畸高且无护城河（需同业基准） | 中度 | 高于同业却无护城河，警惕收入/成本人为调节 |
| 9 | `cip_stuck` | 在建工程长期不转固 | 轻度 | 不转固可规避折旧、美化利润 |

**阈值设计纪律**（踩坑沉淀）：

- 规则 1、2 增加「**实质占比门槛**」：应收/存货 增速虽高于营收，但若应收/营收 < 15%、存货/营收 < 50%，属正常经营波动，不误伤优质公司（如白酒龙头的正常备货）。
- 规则 8 必须依赖 `peerBench`（同业毛利率基准）；缺失时该检查置 `na` 并在 `warnings` 提示，绝不凭空判定。
- 结论用 `InsightBlock.severity` 表达红绿灯：`high`(高危) / `mid`(中度) / `low`(轻度) / `info`(总览)。

## 4. ROE 杜邦（roeModule）

`roe_parent = 净利率 × 总资产周转率 × 杠杆系数`，瀑布图拆解三因子贡献，并标注老唐点评：

> 高 ROE 到底来自高净利（生意好）、高周转（运营强）还是高杠杆（借来的），性质天差地别。

口径对齐赢麻了 `sys/metric/hroe_b2.xs` 的**归母口径**；普通股口径与加权近似在专业版更完整。

## 5. 毛利率与净利润（grossMarginModule / netProfitModule）

- 毛利率：看**水平 + 稳定性**，并与同业基准横向对比（老唐：能长期维持高毛利 = 有护城河；毛利突变 = 产品或会计政策变了）。
- 净利润：用共同比报表看利润构成，并用经营现金流验证含金量。

## 6. 资产 / 存货 / 固定资产 / 产销量

- **资产结构**：饼图看轻重资产，共同比看资产分布。
- **存货**：存货增速 vs 营收、存货周转、跌价准备提示。
- **固定资产**：产能投放节奏、在建工程转固节奏（呼应排雷第 9 条）。
- **产销量**：产量/销量趋势 + 产销率（销量/产量），识别「产大于销」的库存堆积信号。
