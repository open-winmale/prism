> 个人投资者的专业版简化版：聚焦单公司研究，用「六大问题域 × 行业模版」把一家公司的财务讲清楚。
> 结论先行 · 突变检测 · 证据随行 —— 每个数字可核查，缺数据不装懂。

**🌐 在线体验（免安装）**：<https://open-winmale.github.io/prism/>

> 本项目前身为 `open-winmale/report-lens`，2026-10-22 起更名迁移至本仓库。

**财报透视**是一个面向基本面投资者的前端开源项目：打开即看到一份完整的样板研究报告（默认贵州茅台），围绕**六大问题域**（经营 / 资产 / 负债 / 股东权益 / 利润 / 现金流）逐层核查。它把赢麻了专业版的分析框架（异动扫描、排雷判据、现金流质量）移植成纯 TS 引擎，开源可见、逻辑透明。顶部样板画廊可在消费白马、制造排雷等 4 个案例间切换，全部 0 EC。

**交互只有两层**：左栏切页面（1 击），点异动信号看证据图（2 击）——其余内容全部直出，不做折叠与构建式图表。

路线图见 [ROADMAP.md](./ROADMAP.md)。

本开源版默认打开内置样板（3 家真实白酒 + 1 个合成排雷样例）；通过赢麻了开放平台（AppId）可接入真实财报、行业成分与估值，并引流至 [赢麻了专业版](https://winmale.com) 获取附注、盈利预测、股东/公告与提醒等深度能力。

## ✨ 特性

- **打开即成品 + 样板画廊**：`/#/` 直接落到默认样板研究报告；顶部 4 个样板（3 家真实白酒 + 演示·制造）横向切换，快照 0 EC；搜索任意 A 股才走接口。
- **六大问题域**：经营 / 资产 / 负债 / 股东权益 / 利润 / 现金流——每个域回答一个用户问题，配 KPI（带趋势线与公式悬浮）、核心图、突变信号与深度模块。
- **行业模版**：异动阈值、重要性下限、默认深挖方向、六域附注与科目附注全部由行业模版预设（白酒看合同负债与基酒、制造看转固与产能消化、周期看毛利率位置与现金短债比……）——用户只读报告，不需要自己配参数。
- **突变检测三道门**：占比 <1% 不报、绝对额增量 <1% 不报（基数太小不构成有意义的突变）、比率行反推背后科目占比同样过门。检出后每条信号可展开「历史趋势 + 关联指标对比」双图（应收对照营收、经营现金流对照净利……30+ 科目关联映射）。
- **专业三表**：5 年年度 / 8 季季度、原值/同比/占比、sticky 表头与首列、数字右对齐、缺失显示「—」、CSV 导出；三表附录直出可回溯。
- **判据而不是打分**：排雷清单四态（触发/关注/安全/数据不足），证据/为什么/下一步全部直出；Beneish M-Score 八因子先行，缺数据不硬算。
- **数据严谨性**：缺失≠0；累计≠单季（季报口径自动切同季同比）；单位换算收口数据层（原始值传递，展示层只格式化）；审计意见、报告期、数据截至常驻；金融企业直接提示不支持。
- **可复用纯 TS 引擎**：分析逻辑与框架无关（`src/engine`），可同时服务 Vue（本仓库）与 React（赢麻了专业版）。
- **开放平台接入**：内置示例 0 EC；填入自己的 AppId 后查任意 A 股非金融公司，首次约 3.6 万 EC、24h 缓存。
- **合规友好**：不荐股、不给目标价、不做买卖时点；内置免责声明与「估值只回答贵不贵」提示。

## 🚀 快速开始

要求 Node ≥ 18.18。

```bash
npm install
npm run dev        # 启动开发服务器（默认 http://localhost:5173）
npm run build      # 生产构建
npm run test       # 运行引擎单测（Vitest）
npm run typecheck  # 类型检查（vue-tsc）
npm run lint       # Lint（oxlint）
```

内置 4 个样板：**贵州茅台 / 五粮液 / 泸州老窖**（真实年度报表）+ **演示·制造（排雷样例）**（合成数据，刻意构造多项财务异常）。打开 `/#/` 会直接进入样板研究报告，顶部画廊切换。

## 🔌 连接赢麻了开放平台（获取真实数据）

开源版默认用内置演示数据。若要接入真实财报与行业基准，复制 `.env.example` 为 `.env` 并填入开放平台 AppId：

```bash
cp .env.example .env
```

```ini
# .env
VITE_WM_CLIENT_ID=你的开放平台ClientId
VITE_WM_CLIENT_SECRET=你的开放平台ClientSecret
VITE_WM_API_BASE=https://api.winmale.com
VITE_PRO_URL=https://winmale.com
```

填入后，数据提供方自动从内置示例切换为 `LiveProvider`；缺失字段（如扣非净利润、分红历史序列）会优雅降级并在界面提示「连接赢麻了专业版补全」。

> 尚未拥有 AppId？前往 [赢麻了专业版](https://winmale.com) 开通开放平台权限，解锁全量真实数据与机构级附注分析。

## 🧭 单公司研究台（核心体验）

打开 `/#/` 即进入默认样板研究报告（贵州茅台）；左栏六个页面，点击即整页直出：

1. **总览**：结论条（四态判定 + thesis + 证据/风险 chips + 数据完整度 + 审计意见）→ 核心趋势 2×2 → 异动信号（点开即见证据图）→ 六大问题域扫描（定位卡：哪域有事、去哪页看）→ 同业坐标；
2. **经营·资产**：应收/存货/合同负债占营收、收现比 + 资产结构 + 存货/固定资产深度模块；
3. **负债·权益**：资产负债率/有息负债率/流动比率 + 股东权益构成 + 增长来源瀑布 + 质量体检；
4. **利润**：营收同比/毛利率/净利率 + 盈利驱动 + 毛利/净利/ROE 杜邦 +（季报口径）季节性；
5. **现金流**：CFO/净利含金量、FCF、CCC、现金流八型；
6. **估值·风险**：PE/PB/PS、市赚率、股息率、总股本变动 + 同业横截面分位 + 排雷清单 + 跟踪表。

> 设计原则：**结论先行、证据随行、口径诚实、两层交互**。不做 0–100 总分；缺数据不判安全；每个数字都能回到报告期/科目/公式/来源；除「点信号看证据」外无任何折叠。

<details>
<summary><b>🧭 六大问题域</b>（点击展开）</summary>

| 问题域 | 回答的问题 | 主要内容 |
| --- | --- | --- |
| 经营 | 生意运转顺畅吗？营运资金被谁占用？ | 应收/存货/合同负债占营收、收现比、存货周转 |
| 资产 | 家底压在哪？资产质量实不实？ | 现金/产能/商誉占比、资产结构、固定资产效率 |
| 负债 | 欠的钱压不压得住？ | 资产负债率、有息负债率、流动比率 |
| 股东权益 | 股本有没有被稀释？利润有没有留下来？ | ROE、未分配利润、股本变动、增长来源瀑布 |
| 利润 | 赚不赚钱？量价与费用发生了什么？ | 营收同比、毛利率、净利率、盈利驱动、杜邦拆解 |
| 现金流 | 利润是不是真金白银？ | CFO/净利、FCF、CCC、现金流八型 |
</details>

新增分析模块只需在 `src/engine/analysis/` 实现一个 `run*` 函数并在 `useDomainViews.ts` 挂到对应问题域，详见 [`docs/ANALYSIS_MODULES.md`](./docs/ANALYSIS_MODULES.md)。

## 🏗️ 架构

```
src/
├── engine/            # 纯 TS 分析引擎（与框架无关，可被任意前端复用）
│   ├── schema/        # 数据模型 + 六大问题域（problems.ts）+ 行业模版（industry.ts）
│   ├── compute.ts     # 单期/杜邦指标计算
│   ├── derivations.ts # 三表目录树（含负债段/权益段）与派生指标
│   ├── methods/       # 趋势/结构/横向/纵向 四类分析方法
│   ├── laotang/       # 老唐排雷规则清单
│   └── analysis/      # 异动扫描（三道门）/ 排雷 / 质量模型 / 增长来源 …
├── data/              # 内置示例 + 数据提供方（Snapshot / Live）
├── components/ui/     # 通用组件：CompanyHeader / VerdictStrip / KpiTile / StatementTable ...
├── features/
│   ├── research/      # 单公司研究台：6 页路由 + 六域编排（domainSections）+ 异动证据链
│   ├── home/          # 关于/方法论/配额说明
│   └── charts/        # ECharts 适配层（ChartSpec → option 纯函数）
└── styles/            # 主题 token、基础样式、研究台设计系统
```
